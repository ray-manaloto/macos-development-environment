## How Claude Code Discovers Plugins

**Short answer**: Claude Code does **NOT** auto-discover plugins from `.claude/plugins/`. Project-level plugins must be explicitly installed via marketplaces or loaded with the `--plugin-dir` flag during development.

### The Three Ways to Load Plugins

**1. Development Mode (Testing) — `--plugin-dir` flag**
```bash
claude --plugin-dir ./my-plugin
```
This is what you're likely looking for. Use this to test local plugins during development. You can load multiple plugins:
```bash
claude --plugin-dir ./plugin-one --plugin-dir ./plugin-two
```

**2. Installation via Marketplace (Production)**
Plugins must be registered in a marketplace (GitHub repo, local path, or URL) then installed with:
```bash
/plugin install plugin-name@marketplace-name
```
This installs to one of three scopes:
- **User scope**: `~/.claude/plugins/` (global, all projects)
- **Project scope**: `.claude/settings.json` (shared with team)
- **Local scope**: `.claude/settings.local.json` (personal, project-only)

**3. Project-Level Configuration in `settings.json`**
Admins can pre-configure plugin marketplaces in `.claude/settings.json`:
```json
{
  "extraKnownMarketplaces": {
    "my-team-tools": {
      "source": {
        "source": "github",
        "repo": "your-org/claude-plugins"
      }
    }
  }
}
```
