## Summary

Based on thorough research of official Anthropic documentation and recent developments, here are the definitive answers to your questions:

### 1. **Does Claude Max provide any API key or API access?**

**No.** Claude Max (the subscription plan) does **not** provide API keys or direct API access. According to [Anthropic's official support documentation](https://support.claude.com/en/articles/9876003-i-subscribe-to-a-paid-claude-ai-plan-why-do-i-have-to-pay-separately-for-api-usage-on-console), "Claude paid plans and the Claude Console are separate products designed for different purposes."

### 2. **Can Claude Max subscription be used to make litellm/API calls programmatically?**

**Technically yes, but with strict limitations.** There is one officially supported method:

- **LiteLLM gateway with OAuth forwarding**: [LiteLLM's documentation](https://docs.litellm.ai/docs/tutorials/claude_code_max_subscription) shows you can configure a gateway with `forward_client_headers_to_llm_api: true` to forward Claude Max subscription OAuth tokens (in the `Authorization: Bearer` header) to Anthropic's API. This allows per-user authentication using Max subscription usage quotas rather than pay-per-token billing.

However, as of **January 2026**, Anthropic shut down unauthorized third-party usage of OAuth tokens. [Anthropic now enforces this via client fingerprinting](https://github.com/anthropics/claude-code/issues/37686), blocking non-official clients with the error: "This credential is only authorized for use with Claude Code and cannot be used for other API requests."

### 3. **Is there any way to use Claude Max credits for API usage?**

**No direct way.** Claude Max subscription has a usage quota, but it's only accessible through:
- Claude.ai web interface
- Claude Code (the official CLI/IDE extension)
- Claude for Teams/Enterprise products

You cannot use subscription credits for programmatic API calls via `litellm` with standard patterns. The OAuth workaround mentioned in #2 exists but is actively being restricted.

### 4. **What is the relationship between Claude Max subscription and the Anthropic API?**

**They are completely separate billing systems:**

- **Claude Max subscription** ($100/month): Usage-quota-based access to Claude through web, desktop, and Claude Code CLI/IDE extensions
- **Anthropic API**: Pay-per-token billing ($1–$25 per million tokens depending on model). No free tier or bundle with subscriptions.

According to [the official pricing documentation](https://platform.claude.com/docs/en/about-claude/pricing), there is no discount or credit transfer between them. If you have a Max subscription and also use the API, you are charged separately for each.

### 5. **Does Claude Code have a proxy or gateway feature to leverage for API calls?**

**No built-in proxy.** Claude Code itself does not provide a proxy gateway. However:

- **LiteLLM proxy integration**: You can route Claude Code through a [LiteLLM gateway](https://code.claude.com/docs/en/llm-gateway) with proper OAuth token forwarding to use subscription credentials. But this is strictly monitored by Anthropic.
- **Cloud providers**: Claude Code can authenticate via [Amazon Bedrock](https://code.claude.com/docs/en/amazon-bedrock), [Google Vertex AI](https://code.claude.com/docs/en/google-vertex-ai), or [Microsoft Foundry](https://code.claude.com/docs/en/microsoft-foundry) for API access independent of subscriptions.
