### P2 IMPORTANT

**[chezmoi.py:74] `_check_chezmoi_script_drift` checks `proc.stdout.strip()` — `chezmoi diff` non-empty stdout may not mean script drift**

`chezmoi diff --include=scripts` outputs a unified diff of script content changes. An empty diff (no pending scripts) produces empty stdout, which is the correct signal. However, `chezmoi diff` may also emit informational lines, version headers, or preamble text before the actual diff on some versions or with some config options. Checking `proc.stdout.strip()` for truthiness means any non-empty output triggers a WARNING, even if the actual diff lines are just context noise. This is a potential false-positive.

Additionally, the check ignores `proc.returncode`. If `chezmoi diff --include=scripts` exits non-zero (e.g., source directory not found, config error), `proc.stdout` may be empty and no finding is generated — again, a silent false-negative.
