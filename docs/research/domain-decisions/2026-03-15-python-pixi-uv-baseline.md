
# Python Pixi uv Domain Baseline

The Python domain defaults to a repo scoped `pixi.toml` plus `pixi.lock` starter bundle.
The domain team must compare four surfaces before it adopts a realization path:

- repo `pixi.toml`
- optional `pyproject.toml` with `[tool.pixi]`
- `pixi-global.toml`
- `mise` managed Python CLI declarations

Raw `pixi global install` and `uv tool install` remain imperative execution paths until a recorded domain decision adopts a declarative sync model.
